Q table entries:
Q(S,A)←Q(S,A)+α(R+γ*Q(S′,A′)−Q(S,A))
Where,

    S is the current state.
    A is the action taken by the agent.
    S' is the next state the agent moves to.
    A' is the best next action in state S'.
    R is the reward received for taking action A in state S.
    γ (Gamma) is the discount factor which balances immediate rewards with future rewards.
    α (Alpha) is the learning rate determining how much new information affects the old Q-values.

(dit noemt men de temporal difference, het is een formule om te leren uit je voorgaande ervaringen, zelfs als je geen manier hebt om de huidige reward van een spel state te bepalen, het is gebaseerd op de 
bellman's equation die bijna hetzelfde doet maar dan al een model heeft van de game.)
Bellman's equation: recursieve formule die gebruikt wordt om de waarde en optimale actie van een state te detemineren.
    Q(s,a)=R(s,a)+γ maxa ​Q(s′,a)

Door steeds meer states te exploren wordt een actie die sneller naar een reward leid een hogere waarde.

de ϵ-greedy Policy:
Exploration: de agent neemt een random actie, die mogelijke rewards leren mogelijk maakt. kans is ϵ.
Exploitation: De agent neemt de beste actie volgens de Q tabel. kans = 1−ϵ.

met deze dingen ken je al alles van dit algoritme, hier is de gegeven voorbeeld code die een raster van 4x4 vormt en 1 goal state heeft, hierbij zal er dan geleerd worden welke acties (stapsgewijs bewegen over het raster)
de beste zijn.

import numpy as np
import matplotlib.pyplot as plt

n_states = 16         
n_actions = 4          
goal_state = 15        

Q_table = np.zeros((n_states, n_actions))
learning_rate = 0.8
discount_factor = 0.95
exploration_prob = 0.2
epochs = 1000

def get_next_state(state, action):
    row, col = divmod(state, 4)  

    if action == 0 and col > 0:        
        col -= 1
    elif action == 1 and col < 3:      
        col += 1
    elif action == 2 and row > 0:     
        row -= 1
    elif action == 3 and row < 3:     
        row += 1

    return row * 4 + col

for epoch in range(epochs):
    current_state = np.random.randint(0, n_states)  

    while True:
        if np.random.rand() < exploration_prob:
            action = np.random.randint(0, n_actions)
        else:
            action = np.argmax(Q_table[current_state])

        next_state = get_next_state(current_state, action)

        reward = 1 if next_state == goal_state else 0

        Q_table[current_state, action] += learning_rate * (
            reward + discount_factor * np.max(Q_table[next_state]) - Q_table[current_state, action]
        )

        if next_state == goal_state:
            break

        current_state = next_state
